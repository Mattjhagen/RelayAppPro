# App Assets

Place your app assets here:

- **icon.png** - App icon (1024x1024)
- **adaptive-icon.png** - Android adaptive icon (1024x1024)
- **splash.png** - Splash screen (1284x2778 for best results)
- **favicon.png** - Web favicon (48x48)

## Quick Asset Generation

You can use the provided script to generate placeholder assets:

```bash
cd ~/opencode-mobile
./generate-assets.sh
```

Or create your own custom assets using:
- Figma
- Canva
- Adobe Illustrator
- Online icon generators

## Icon Guidelines

### App Icon (icon.png, adaptive-icon.png)
- Size: 1024x1024 pixels
- Format: PNG with transparency
- Style: Simple, recognizable at small sizes
- Colors: Match your brand or use the OpenCode theme

### Splash Screen (splash.png)
- Size: 1284x2778 pixels (or 1242x2688)
- Format: PNG
- Background: Solid color matching your theme
- Center logo/text should fit in safe area (1024x1024 center)

### Favicon (favicon.png)
- Size: 48x48 pixels
- Format: PNG with transparency
- Should be recognizable at tiny sizes

## Color Scheme Suggestions

**Dark Theme:**
- Primary: #3b82f6 (Blue)
- Background: #0f172a (Dark blue-black)
- Text: #e2e8f0 (Light gray)

**Light Theme:**
- Primary: #2563eb (Blue)
- Background: #ffffff (White)
- Text: #1e293b (Dark gray)

## Using Emoji as Icons (Quick Start)

For rapid prototyping, you can use text/emoji as app icons:

1. Open any design tool
2. Create 1024x1024 canvas with dark background
3. Add "⚡" or "💻" or "🤖" emoji centered
4. Export as PNG

This gets you started quickly. Replace with professional designs later.
